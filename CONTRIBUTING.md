# Contributing
We welcome all contributors to submit fixes/improvements to VRCFaceTracking. To help us filter out low-quality code we ask the following:

## AI Usage
It's alright to submit AI-generated code so long as:
- You're alright with accepting the liability of the code
- You have thoroughly tested the code on your own
- You understand what the code does
As a requirement: **You may not submit AI-generated PRs.** Submit and write the Pull Request yourself, otherwise it will be declined.

## Translation
Machine-generated translations are not allowed, and will not be accepted. 
We do this as it's impossible for us to verify translation *accuracy,* only that it isn't totally incorrect. AI is unable to grasp the nuances of every intended meaning that fluent speakers understand.
